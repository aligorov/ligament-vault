# Ligament Vault — Отказоустойчивый гео-кластер SFTP / FTPS / Web / WORM

Готовый файловый кластер корпоративного уровня на **3–5+ обычных Linux VPS в разных дата-центрах без VPN-оверлея** (`SFTPGo + SeaweedFS 4.x + Patroni/PostgreSQL 16 + etcd + mTLS`) с единой **HTTPS Веб-панелью управления (`:9443`)**, браузерным файловым клиентом (`:443`), неизменяемым **WORM-архивом (`COMPLIANCE`)** и интеграцией с **Ligament 2FA**.

---

## ⚡ Установка одной командой

Подключитесь по SSH (`root`) к главному серверу (**Ubuntu 22.04 / 24.04 LTS**) и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/aligorov/ligament-vault/main/install.sh | sudo bash
```

**Что сделает установщик за ~30 секунд:**
1. Установит Docker, Compose, `age` и все системные утилиты.
2. Сгенерирует все криптостойкие пароли, JWT и ключи шифрования автоматически (никаких ручных конфигов).
3. Запустит **HTTPS Веб-панель управления на порту `9443`** и выведет в консоль готовую ссылку, логин и пароль.

Дальше откройте `https://<IP_СЕРВЕРА>:9443` в браузере:
- **Подключите остальные чистые VPS прямо по SSH из браузера** (укажите IP, порт и разовый `root`-пароль от хостера — панель сама зайдет на сервер, пропишет SSH-ключ, установит Docker и подготовит диск).
- Нажмите одну кнопку **«🚀 Объединить в кластер и установить всё»** — все серверы автоматически свяжутся по mTLS и соберутся в единый отказоустойчивый кластер (а позже точно так же в 1 клик можно подцепить 4-й или 5-й VPS на лету!).

## 🌐 Два веб-интерфейса из коробки

| Интерфейс | Адрес | Для кого и зачем |
| :--- | :--- | :--- |
| **Панель управления кластером (`Ligament Vault UI`)** | `https://<IP_или_ДОМЕН>:9443` | **Администратор:** установка кластера в 1 клик, живой мониторинг нод/ДЦ/БД/дисков, создание клиентов (`/work` + `/worm`), квоты, настройка `Ligament 2FA`, бэкапы, добавление нод, живая консоль задач |
| **Файловый веб-клиент (`WebClient`)** | `https://<ДОМЕН>:443` | **Пользователи:** загрузка, скачивание и просмотр папок `/work` и `/worm` прямо в браузере (TLS 1.3 + поддержка 2FA) |

Помимо браузера, пользователи подключаются по **SFTP (`порт 2022`)** и **FTPS Explicit/Implicit (`порт 21`, PASV `50000–50199`)**.

## 🛡 Ключевые возможности

- **Гео-распределение без VPN:** прямое соединение между ДЦ по сквозному **mTLS (ECDSA P-256)** с Zero-Knowledge Remote-CSR (приватные ключи никогда не покидают серверы) и 4 JWT-ключами SeaweedFS.
- **Два типа хранилища у каждого клиента:**
  - `/work` — рабочий каталог с версионированием и докачкой оборванных загрузок.
  - `/worm` — неизменяемый архив (`S3 Object Lock COMPLIANCE`): загруженный файл невозможно удалить или перезаписать ни клиенту, ни администратору до истечения срока хранения.
- **Автоматический Failover (`RTO 10–60 сек`):** внешний арбитр с 5 воротами проверки (`5-Gate Auto-Failback`), поддержкой **Cloudflare DNS / Hetzner & DigitalOcean Floating IP** и мгновенным сбросом подвисших соединений через `TCP RST` (`fence-edge`).
- **Защита секретов (`age` в RAM):** пароли БД, S3 и KMS хранятся в зашифрованном `secrets.env.age` и расшифровываются только в оперативную память.
- **Полная автономность образов:** предсобранный образ PostgreSQL 16 + Patroni + pgBackRest публикуется в `aligorov/ligament_vault_patroni:16` (`ghcr.io/aligorov/ligament_vault_patroni:16`) с автоматическим локальным fallback из [Dockerfile.patroni](file:///Users/aleksey/Documents/ftp/Dockerfile.patroni).

## 💻 Управление из терминала (`ligactl`) — опционально

Все действия доступны в веб-панели `:9443`, но при необходимости установлена глобальная команда `ligactl`:

```bash
ligactl panel status                                              # Статус и пароль веб-панели :9443
ligactl status                                                    # Состояние всех узлов, БД, SeaweedFS и SSL
ligactl user add --username bank1 --quota-gb 100 --generate-password  # Создать клиента (/work + /worm)
ligactl scale add --ip 203.0.113.40 --dc dc4                      # Добавить 4-й узел в кластер
ligactl dr restore --latest                                       # Восстановить весь кластер из S3 бэкапа
ligactl publish-image                                             # Собрать и запушить образ Patroni в Docker Hub
```
